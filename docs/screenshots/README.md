# Capturas del flujo

Estas cuatro capturas son las que el README principal enlaza. **Faltan por
tomar**: se capturan a mano desde el navegador, con el stack levantado y el seed
ejecutado.

| Archivo | Qué debe mostrar |
|---|---|
| `01-acceso.png` | La pantalla de acceso completa, con el panel izquierdo y el formulario. |
| `02-extraccion.png` | Una operación ya extraída: la fotografía a la izquierda y la tarjeta de características con el nombre y la función editables. |
| `03-revision.png` | La clasificación propuesta con la barra de confianza segmentada, la justificación y las alternativas. Usa la **bocina** o el **cargador USB**: caen bajo el umbral y muestran el banner «Requiere revisión», que es el momento que da sentido al producto. |
| `04-pedimento.png` | La liquidación y la vista previa del PDF en la misma pantalla. |

Sugerencias:

- Ventana de 1440 px de ancho o más, para que el panel lateral y el contenido
  aparezcan lado a lado.
- Zoom del navegador al 100 %.
- Formato PNG.
